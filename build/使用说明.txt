Pile 0.2.0 —— 把散落在各个仓库和本地目录里的 Markdown 笔记聚到一个书架

一、怎么用
  1. 把整个文件夹放在一个「能写文件」的地方（例如 D:\Pile 或 U 盘），不要放 C:\Program Files
  2. 双击 Pile.exe
  3. 右上角 ⚙ → 填 GitHub 仓库地址，或直接填一个本地笔记目录
  4. 打开书，左侧目录点章节就能读；顶栏可以搜索、切换主题

二、你的数据都在 data\ 里（首次运行自动创建）
  data\books.json         书架清单，一本书一段，可以手工编辑
  data\config.json        配置 + 加密后的 token（只有这台电脑的这个账户能解开）
  data\window-state.json  窗口大小和位置
  data\repos\            从 GitHub 克隆下来的仓库
  data\trash\            丢弃本地改动之前自动备份的 patch
  data\logs\app.log      运行日志

  备份就整个 data\ 一起备份；换电脑就把整个文件夹一起拷走，
  书架、配置、已下载的仓库都会跟着走。

三、注意
  · 程序目录写不进去时会直接提示并退出（刻意设计，避免数据被悄悄写到别处）
  · 同一个文件夹只能开一个窗口；不同文件夹的副本可以同时开
  · Pile 只会拉取最新内容，不会提交、不会推送，也不会改动你的仓库
  · 私有仓库的 token 只勾 Contents: Read-only 就够
  · 从旧安装版升级过来时，首次启动会把 %APPDATA%\Pile 里的书架复制到 data\
  · 没有代码签名：首次运行 Windows SmartScreen 可能提示，选「更多信息 → 仍要运行」
